Guia Rápido do CaptaFácil

Nova Captação

Clique em "Nova Captação" para iniciar o preenchimento de uma ficha de imóvel. O formulário é dividido em etapas para facilitar.

Minhas Captações

Acesse o histórico de todas as suas captações. Você pode buscar, filtrar, editar, gerar PDF e solicitar assinaturas a partir desta tela.

Gerar PDF

Em "Minhas Captações", cada item tem um botão "Gerar PDF". Isso cria a ficha oficial, idêntica à planilha, pronta para impressão ou envio.

Coletar Assinatura Digital

Use o botão "Coletar Assinatura" para gerar um link único. Envie este link para o proprietário, que poderá assinar digitalmente de qualquer dispositivo. O link expira em 48 horas.

Status da Assinatura

Você pode verificar o status da assinatura (Pendente, Assinado, etc.) clicando no selo de status em cada captação no seu histórico.

Fale Conosco

Use o botão "Enviar Mensagem" para enviar sugestões ou relatar problemas diretamente para a administração do sistema.
